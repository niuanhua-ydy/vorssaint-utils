# 命令栏：系统短命令与即时答案

这些是命令栏内置语法，不是终端或任意 Shell 执行器。打开命令栏后直接输入；仅列出结果不会执行系统操作，选中结果并按回车才会执行。

## IP 地址

| 输入 | 行为 |
| --- | --- |
| `ip`、`本机ip`、`ip地址`、`内网ip`、`局域网ip` | 读取本机接口，显示 IPv4；回车复制所选地址 |
| `publicip`、`公网ip`、`外网ip` | 显示本机地址，并按需查询公网出口 |
| `ip` 列表中的「查询公网 IP」 | 保持命令栏打开，联网查询公网出口 |

- 优先显示 macOS 标识的主接口，并显示接口名称和 BSD 名称。有效的 VPN 接口也可显示。
- 不显示 loopback、未启动接口、`169.254.*` 链路本地地址及 `198.18.*` / `198.19.*` Fake-IP。
- 当前是 IPv4 功能，不宣称支持 IPv6。没有可用地址时会明确提示。
- `ip` 本身不联网。公网查询分别显示 ipify / IPIP 观察到的地址；代理或路由可能使两者相同或不同，不能直接认定哪一个是「真实 IP」。
- 快照与公网结果只保留在本次命令栏打开期间。关闭后重新打开会重新读取；没有后台轮询。失败或部分失败可回车重试，不自动无限重试。
- 在「答案」来源关闭时不读取接口、不查询公网。

## 系统短命令

| 命令 | 行为 |
| --- | --- |
| `lock` / `锁屏` | 锁屏 |
| `sleep` / `睡眠` | 系统睡眠 |
| `sleepdisplays` / `息屏` | 关闭显示器 |
| `screensaver` / `屏保` | 启动屏幕保护程序 |
| `trash` / `废纸篓` | 在 Finder 中打开废纸篓 |
| `emptytrash` / `清空废纸篓` | 清空废纸篓，沿用原有确认设置 |
| `logout` / `注销` | 注销，沿用原有确认设置 |
| `restart` / `重启` | 重启，沿用原有确认设置 |
| `shutdown` / `关机` | 关机，沿用原有确认设置 |
| `ejectall` | 安全推出所有符合现有规则的磁盘 |
| `volup` / `voldown` | 系统输出音量增减一格（6.25 个百分点） |
| `mute` | 切换静音 / 取消静音；设备没有静音控制时不提供 |

短命令是原有命令的别名，不会绕过功能安装状态、隐藏设置或确认设置。设备不支持软件音量时会提示失败，不初始化整个混音器来读取一次音量。

`quitall` 只在「退出应用」功能本身可用时指向已有命令。当前定制构建排除了该功能，因此不新增或重新启用这个批量操作。

## 动词 + 目标

| 输入示例 | 行为 |
| --- | --- |
| `quit Safari` | 列出匹配的运行中应用；确认后请求正常退出 |
| `hide Chrome` | 隐藏匹配的运行中应用 |
| `forcequit Safari` | 列出匹配应用；强制退出前再次确认未保存工作风险 |
| `eject USB` | 列出符合现有磁盘排除规则的目标卷；确认后安全推出 |
| `port 3000`、`port :3000` | 精确查找监听 TCP 端口；沿用端口管理器的操作与确认 |
| `port node` | 按占用端口的进程名查找 |
| `kill node` | 列出匹配进程；确认后发出正常终止请求（SIGTERM） |
| `kill 4242` | 精确匹配 PID 4242，不按 PID 前缀匹配 |
| `kill :3000` | 终止占用 TCP 3000 的进程，**绝不把 3000 当作 PID** |
| `kill -9 :3000`、`kill -9 4242` | 显式强制终止，确认后执行 |

- 单独输入 `quit`、`hide`、`forcequit`、`eject`、`port`、`kill` 会列出可用目标，不批量执行。
- `kill -KILL` / `kill -sigkill` 和 `kill -TERM` / `kill -15` / `kill -sigterm` 等已有信号写法继续可用；不接受任意信号或任意 Shell 参数。
- 名称不区分大小写，应用名称支持空格。端口仅接受 1–65535；不允许 PID 0、负 PID 或进程组操作。
- 精确命令未匹配目标时不回退到不相关的模糊搜索结果。命令只在全局搜索解释；进入某一类别后仍保持该类别原有的筛选语义。
- 应用操作使用现有「应用」来源开关；进程命令遵守 Kill Process 的可用状态、命令栏开关和来源开关；端口命令遵守 Port Manager 的可用状态和来源开关。
- 进程、端口复用现有服务，保留受保护进程和启动时间校验；运行中应用在执行前校验 PID、bundle ID 和启动日期。推出磁盘前重新检查卷身份和排除规则。

## 汇率换算

支持示例：

```text
100 USD to CNY
USD 100 in EUR
100美元转人民币
100万日元是多少人民币？
2w港币兑美元
美元/人民币
USD CNY
100USD
```

- 支持法币 ISO 代码、系统本地化币种名称、常见中文别名和货币符号。`$` 视为 USD，`¥` / `￥` 视为 CNY；不确定时请明确输入 ISO 代码。
- 两个币种不写金额时按 1 换算。只有「金额 + 币种」时换算为本机地区币种；源币种已是本机币种时换算为 USD，本机币种是 USD 时则换算为 EUR。
- `k` 为千，`w` / `万` 为万，`m` 为百万。不把普通文本、未完成换算、单独币种名或加密货币触发为联网查询。
- 输出明确的币种代码，回车复制换算结果，不自动粘贴到其他应用。
- 使用 [Exchange API](https://github.com/fawazahmed0/exchange-api) 的每日参考价，先请求 jsDelivr，失败回退到 Cloudflare Pages。不是实时交易报价；结果显示汇率日期。
- 只下载通用 USD 汇率表；金额、输入文本、目标币种、应用列表和本机地址不上传。服务方仍可看到正常 HTTPS 请求信息，包括公网出口。
- 本地缓存 6 小时。离线且有缓存时保留参考结果，并明确标注「缓存参考价（可能过期）」；无可用报价时提供手动重试。
- 完成语法识别后防抖 300 ms 才发请求；离开查询、关闭命令栏或关闭相应来源时取消未完成的请求。无后台更新任务。关闭「计算器」来源后不查询汇率。

## 验证

不启动应用、不执行锁屏、结束进程或推出磁盘的定向测试：

```sh
Tools/test-system-commands.sh
```

它直接编译生产解析、查询服务及网络接口读取代码，并提取实际的旧 PID 解析方法测试端口/PID 隔离。网络测试使用注入响应，覆盖离线、缓存、防抖、取消和备用源，不依赖真实第三方服务。

标准测试入口（会编译其他所有测试夹具）：

```sh
./build.sh --test-suite=system-commands --test-suite=command-bar --test-suite=developer-tools
```

开发包构建（不安装、不启动）：

```sh
./build.sh --dev
```
